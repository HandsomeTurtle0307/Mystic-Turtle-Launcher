功能特性

[ 01 ]

版本隔离

各版本独立保存模组、配置和存档。关闭隔离时会自动迁移版本文件，不用手动搬目录。

[ 02 ]

账户管理

支持多账号，每个账号可单独设置登录方式，互不影响。

[ 03 ]

界面与动效

原生 Qt6 玻璃界面，页面切换和卡片动画统一、简洁。

[ 04 ]

Modrinth 下载

在启动器内搜索并安装 Modrinth 的模组、整合包和资源包。

[ 05 ]

完善的设置项

Java、内存、JVM、下载源、代理和窗口参数都可按版本单独调整。

[ 06 ]

自动修复依赖

启动前检查 Java、资源和依赖，能修的直接处理，不能修的说明原因。

[ 07 ]

Live2D 看板娘

空白主页可切换多张全身立绘，支持呼吸、风动和眼神跟随。

[ 08 ]

轻量原生

Qt6 + C++17 构建，不依赖 Electron，启动器本身保持轻量。

BUILT-IN MULTIPLAYER

内置 P2P 联机

启动器内置 EasyTier，不需要公网 IP 或手动端口转发。双方加入同一个虚拟房间后，用虚拟 IP 和游戏端口就能在 Minecraft 里直接连接。

EasyTier 组网 无需公网 IP 一键复制 IP:端口

首次使用需允许 EasyTier 和 Java 通过防火墙；创建虚拟网卡需要管理员权限。

  1. 01
    双方加入同一房间输入相同的房间名和密码。
  2. 02
    房主开放局域网进入游戏，点击“对局域网开放”。
  3. 03
    复制 IP 和端口把房主虚拟 IP 与游戏端口发给朋友。
  4. 04
    直接连接加入朋友在多人游戏中粘贴 IP:端口。
